# Book & Go agent skills

Agent skills for [Book & Go](https://www.bookandgo.app), the white-label booking app and back-office platform for padel, tennis, pickleball, fitness, wellness and polo clubs.

## Install

```bash
npx skills add joaquinreyes/bookandgo-skills
```

Or browse it on [skills.sh](https://skills.sh/joaquinreyes/bookandgo-skills).

## Skills

| Skill | What it does |
| --- | --- |
| [`bookandgo`](skills/bookandgo/SKILL.md) | Explains Book & Go accurately, submits quote, demo, brochure and contact requests through the public API after the user confirms them, and connects Book & Go club admins to the Book & Go MCP server (`https://mcp.bookandgo.app/mcp`, OAuth) to manage bookings, courts, customers and memberships. |
